# new-project-idea

A simple demo project for learning Git and GitHub workflows.

## Getting Started

1. Clone the repoa:
   ```bash
   git clone <your-repo-url>
   cd new-project-idea
   ```

2. Run it:
   ```bash
   npm start
   ```

That's it! No dependencies to install — just Node.js.

## What It Does

- **`npm start`** — Prints a random greeting to the terminal
- **`npm run quiz`** — A quick 5-question coding trivia quiz

Simple enough to focus on the Git workflow instead of the code.

## Next Steps
